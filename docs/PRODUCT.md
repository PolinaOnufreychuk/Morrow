# Product — Designer Workspace

## Problem

Freelance designers scatter project context across Figma, Google Drive, chat apps, and notes apps. Switching between tools to answer "what's the status of this client's project?" wastes time and breaks focus.

## Solution

A single hub where a designer organizes every client project: status, deadline, linked design files, light attachments, tasks, and notes — in one place. Designer Workspace does not replace Figma/Drive; it organizes around them.

## Target User (MVP)

Solo freelance designer working with multiple clients, using this as a personal daily-use productivity tool. Not a team tool in v1.

## Core Value Proposition

"Open one dashboard, see every project's status and next action — without hunting through five apps."

## Product Principles

See [../CLAUDE.md](../CLAUDE.md) for philosophy, UX rules, and development rules that every feature must satisfy.

## MVP Goal

Ship a personal workspace that replaces the designer's ad-hoc mix of notes app + spreadsheet + bookmarks for tracking client projects.

## Explicitly Out of Scope (v1)

- Teams, workspaces shared with others, permissions/roles
- Payments, subscriptions, premium tiers
- Full file hosting/versioning (only light attachments + external links)
- Native Figma/Drive API integrations (manual links only)
- Mobile app
- Notifications/reminders

These are deferred, not rejected — see [ROADMAP.md](ROADMAP.md). The data model in [DATABASE.md](DATABASE.md) is designed so teams/workspaces can be added later without a rearchitecture.

## Success Signal for MVP

The designer prefers opening Designer Workspace over their old spreadsheet/notes setup for at least a few real client projects.
